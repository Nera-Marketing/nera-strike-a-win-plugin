== Description ==

Strike A Win adds a skill-based competition mechanic on top of WooCommerce and Lottery for WooCommerce:

* Players buy runs on a competition (tiered, fixed-price entry).
* Each run is a timed, increasing-difficulty quiz, scored on the server.
* Correct answers mint real Lottery for WooCommerce tickets entered into the competition draw.

A no-oversell reservation pool guards ticket ceilings, and the flow is compliance-locked for the Gambling Act 2005 skill exemption.

**Requires:** WooCommerce (and Lottery for WooCommerce for ticket minting).

== Installation ==

1. Install and activate **WooCommerce** (and **Lottery for WooCommerce**).
2. Install and activate this plugin.
3. Configure competitions and tiers, then enable the frontend UI from the plugin's admin controls.
